Firebase without the ceremony

Firescope

A convention-first framework for Firebase apps. Keep Firebase's power while removing repetitive setup for functions, hosting, generated config, local env files, emulator wiring, and deploys.

View on GitHub Releases 
npx firescope@latest init my-app
cd my-app
npm install
npx firescope connect
npx firescope dev

Convention-first functions

Drop files into src/functions and Firescope generates Firebase-compatible exports.

Typed Firestore helpers

Define your data model once and get typed collections, docs, and collection groups.

Clean deploy output

Builds into .firescope/functions so app source stays focused on product code.
